# 🌅 Interactive Good Morning Love Page

A romantic, mobile-first, multi-layered single-page web application designed to surprise your partner with a personalized good morning experience. Built with pure HTML, CSS, and Vanilla JavaScript—zero external dependencies or frameworks required.

## ✨ Features

* **3-Layer Depth Architecture:**
  * **Layer 1 (Hero Sunrise):** Warm sunrise gradient palette with floating hearts and touch/mouse-reactive parallax depth.
  * **Layer 2 (Sticky Stacking Story Cards):** Smooth scroll-driven stacking cards that layer over one another to reveal morning notes.
  * **Layer 3 (Sequential Quote Reveal):** An interactive button that sequentially unlocks 8 romantic quotes (`1/8` to `8/8`) with a dynamic progress bar and a celebratory heart-shower animation upon completion.
* **Glassmorphism UI:** Translucent frosted-glass cards with subtle borders and warm ambient glow effects.
* **Mobile-First & Responsive:** Optimized for touch screens, mobile viewports, and desktop browsers alike.
* **Single-File Portability:** Everything (HTML structure, CSS styling, and JS interactivity) is self-contained in a single `index.html` file for instant deployment.
